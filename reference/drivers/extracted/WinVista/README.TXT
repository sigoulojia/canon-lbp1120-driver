1. Scaling

Some applications may not print correctly when scaling is set at 
other than 100% by LBP-1120 Printer Setup or Properties. In this 
case, please set its scaling at 100%. If the application has own 
its scaling function, please set scaling from the application.

==================================================================

2. Overlay

Depending on its application, the printout using overlay form may 
be different from what you expect to be printed. For example, the 
contents of overlay form beyond the printing area may not be 
printed unless changing its printing area (or margin) setting. 
Please try to print it setting its margin as wide as to fit all 
contents of overlay form in the printable area.

==================================================================

3. Halftone

The Halftone settings are valid when printing colored bitmap, 
area filling, and colored text. However the Smooth setting is 
only valid when printing colored bitmap.

==================================================================

4. Toner Saver

Using Toner Saver mode, the objects filled with some graphic 
patterns may not be printed as shown on the display.

==================================================================

5. Printing On-Line Help: Windows 2000/XP/Vista

If you want to print the contents of the On-Line Help, start up 
the [Canon LASER SHOT LBP-1120 Help] from the Canon LASER SHOT 
LBP-1120 group.

==================================================================

6. Uninstalling network printer that other user connected: 
   Windows 2000/XP/Vista

When you execute the [Canon LASER SHOT LBP-1120 Uninstallation] 
on the PC that other user have already connected to the Canon 
LBP-1120 network printer servers, information of the Canon 
LBP-1120 network printer that other user connected will not be 
removed. In this case, other user should remove his Canon 
LBP-1120 printer icon before you execute uninstallation.

==================================================================

7. Restriction on Windows 2000/XP/Vista network printer

When a network printer is installed on Windows 2000/XP/Vista, even 
though you change its connection destination to a local port, the 
printer cannot be used as a local printer. If you need to 
establish a local printer, you must install a printer driver, 
selecting a local port.

==================================================================

8. Restarting Windows with a remaining print job: Windows 2000/XP/Vista

If you need to restart Windows 2000/XP/Vista with a remaining 
LBP-1120 print job, first double-click the LBP-1120 in the Printers 
folder and pause the print job. 
Then restart Windows 2000/XP/Vista.

==================================================================

9. Windows 2000/XP/Vista network printer installation

When installing a network printer on Windows 2000/XP/Vista, it is 
recommended to install the printer with administrative privilege.
If the printer is however installed by clients himself without 
administrative priviledge, some functions may be unavailable due to 
the restriction of OS security.

[Unavailable functions 1] 
- "Canon LASER SHOT LBP-1120" group is not created.
- When initializing Windows, the Printer Status Window is not started
  automatically.

[Conditions]
(When the client setting can satisfy all of the following conditions);
- Without administrative and power-user privilege.
- File system is "NTFS".


[Unavailable functions 2] 
- Voice message of Printer Status Window is not functioned properly.
- Uninstaller can't be registered in "Add/Remove Programs".
  ([Add or Remove Programs] for Windows XP; [Uninstall a program] for 
  Windows Vista)

[Conditions]
 (When the client setting can satisfy all of the following conditions);
- Without administrative and power-user privilege.

==================================================================

10. Installation in Windows XP/Vista multi-user environment

When Canon LBP-1120 is installed in Windows XP/Vista, do not install 
it for the user switched by the "Fast User Switching" function of 
Windows XP/Vista.
When using the Fast User Switching function, be sure to log on 
again before installation.

==================================================================

11. Running the Printer Status Window after Installing the Printer 
    Driver (Windows Vista)

If you do not restart the computer after installing the printer 
driver, the Printer Status Window may not run automatically when 
you print.
In this case, restart the computer or run the Printer Status Window 
manually.

==================================================================

12. Display of status when printer is used by multiple Windows XP/Vista 
    users

If the user is changed with the Fast User Switching function of 
Windows XP/Vista, the printer status cannot be displayed in the 
Printer Status Window.
To display the status, log on again, then open the Printer Status 
Window.

==================================================================

13. CAPT Windows Firewall Utility

If you are using an operating system equipped with Windows Firewall, 
such as Windows XP Service Pack 2, as a print server, communication 
with the client computers is controlled by Windows Firewall.  The 
[CAPT Windows Firewall Utility] is a utility for configuring Windows 
Firewall to unblock or block this communication with the client 
computers.
The [CAPT Windows Firewall Utility] is located either in the 
[WF_UTIL] folder of the folder that is created when you uncompress 
the downloaded file, or in the [English] - [WF_UTIL] folder in the 
supplied [LBP-1120 User Software] CD-ROM.
Refer to "note_ex.pdf" for more details on the [CAPT Windows Firewall 
Utility].

==================================================================

14. About the Client-Side Settings for Using the Printer Sharing Function

If you are using Windows XP Service Pack 2 or another operating 
system equipped with Windows Firewall on the client side, configure 
the following settings. If you do not setup the following settings on 
the client side, the printer status may not display properly in the 
Printer Status Window and you may not be able to access some of the 
printer functions.
(1) Display the [Windows Firewall] ([Windows Firewall Settings] for 
    Windows Vista) dialog box.
    For Windows XP: From the [Start] menu, select [Control Panel], 
    and then click [Network and Internet Connections] -> [Windows 
    Firewall].
    For Windows Vista: From the [Start] menu, select [Control Panel], 
    and then click [Allow a program through Windows Firewall]. (If 
    the [User Account Control] dialog box appears, click [Continue].)
(2) On the [Exceptions] sheet in the [Windows Firewall] dialog box, 
    place a checkmark next to [File and Printer Sharing], and click 
    the [OK] button.

==================================================================

15. Characters for the Printer Name (Windows Vista)

When an "@" character is used in the name of the printer, the printer 
will become unrecognizable by the operating system because of an 
invalid printer name thus disabling printing, operation and setup.

==================================================================

16. Access Permission to the Printer Properties (Windows Vista)

When you log on to an Administrator account that is different from the 
one used to install the printer driver, you cannot access the printer 
properties with Administrators permission.
To access the printer properties, right-click the icon for the printer, 
and then select [Run as administrator].

==================================================================

17. Printing Thin Lines (Windows Vista)

In certain applications, thickness of a line can be set to a value 
smaller than 1 pt but the actual thickness in the printout may be 
equivalent to that of a 1 pt line.

==================================================================

18. Settings for Printing on Windows Vista (Windows Vista)

Before printing on Windows Vista, perform the following settings.
If you print without performing the settings, the data may not be 
printed as specified in the printer driver.
(1) Right-click the icon for the printer, then select [Properties].
(2) Display the [Advanced] sheet.
(3) Select [Spool print documents so program finishes printing faster], 
    then select [Start printing after last page is spooled].
(4) Click [OK].

==================================================================
