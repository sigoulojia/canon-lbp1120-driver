## 2. Connector J1: External USB Host Interface

- **Type:** USB Type-B Female Right-Angle Through-Hole Connector.
- **Specification:** Universal Serial Bus Specification Revision 1.10.

| Pin # | Contact Name | Cable Color | Signal Function & Characteristics |
| :---: | :--- | :--- | :--- |
| **1** | `VBUS` | Red | +5.0V DC supply from host root port / hub (monitored for cable insertion). |
| **2** | `D-` | White | USB Differential Data Line Minus. |
| **3** | `D+` | Green | USB Differential Data Line Plus (features 1.5 k$\Omega$ pull-up to 3.3V). |
| **4** | `GND` | Black | Ground power return. |
| **Shell** | `Shield` | Braided | Outer metal shell connected to printer metal chassis chassis ground. |

## 3. Connector J202: Laser / Scanner Assembly Harness

- **Location:** Engine Controller PCB to Laser Optics Box.
- **Conductors:** 8 pins.

| Pin # | Signal Name | Direction | Description |
| :---: | :--- | :---: | :--- |
| **1** | `+5V` | Engine $\rightarrow$ Laser | Logic supply for laser driver PCB and optical beam detector. |
| **2** | `GND` | Ground | Common optical ground. |
| **3** | `/BD` | Laser $\rightarrow$ Engine | Beam Detect raw photodiode pulse. |
| **4** | `LD_EN` | Engine $\rightarrow$ Laser | Laser Diode Emission Safety Enable (gated by top cover switch `SW301`). |
| **5** | `/VDO` | Engine $\rightarrow$ Laser | Laser cathode modulation input. |
| **6** | `+24V` | Engine $\rightarrow$ Scanner | Power supply for polygon mirror brushless motor. |
| **7** | `MTR_ON` | Engine $\rightarrow$ Scanner | Polygon mirror motor run enable line. |
| **8** | `MTR_CLK` | Engine $\rightarrow$ Scanner | Reference frequency clock stabilizing polygon motor at 18,000 RPM. |

## 4. Connector J203: Sensors & Solenoid Harness

- **Location:** Engine Controller PCB to Paper Path Sensors & Solenoid.
- **Conductors:** 10 pins.

| Pin # | Signal Name | Description |
| :---: | :--- | :--- |
| **1, 2** | `SL1_DRV` / `+24V` | Paper Pick-up Solenoid drive coil (24V active-low transistor sink). |
| **3, 4** | `PS201_SIG` / `GND` | Paper Delivery Sensor photointerrupter emitter/detector lines. |
| **5, 6** | `PS202_SIG` / `GND` | Paper In-Tray Empty Sensor photointerrupter emitter/detector lines. |
| **7, 8** | `SW301_INT` / `+24V` | Top Cover Interlock microswitch safety loop. |
| **9, 10** | `TONER_SENSE` / `GND` | Toner level capacitive antenna sensing rod inside cartridge bay. |
